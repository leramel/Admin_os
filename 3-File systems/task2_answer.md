### 2.Где обычно хранятся домашние каталоги обычных пользователей?
В директории /home
Для каждого пользователя создаётся своя поддиректория с его именем /home/user

### 3.Где находится домашний каталог суперпользователя?
В отдельной директории /root в корне файловой системы
### 4.Где обычно хранятся основные системные конфигурационные файлы?
В директории /etc
Например:
* ```shell
  /etc/passwd - информация о пользователях
  ```
* ```shell
  /etc/hostname - имя хоста
  ```
### 5.Объясните назначение каталогов
  
```shell
/bin (binaries)
```
Содержит основные исполняемые файлы (бинарники), необходимые для работы системы и всех пользователей.
Это базовые команды, которые должны быть доступны даже если /usr ещё не смонтирован.
Примеры: bash, ls, cp, mv, cat, grep

```shell
/sbin (system binaries)
```
Содержит системные исполняемые файлы, необходимые для администрирования и управления системой.
Эти команды обычно требуют прав root.
Примеры: fdisk, ifconfig, reboot, iptables, mkfs

```shell
/usr/bin
```
Содержит исполняемые файлы пользовательских приложений и утилит, которые не являются критически важными для загрузки системы.
Примеры: python, gcc, vim, wget, curl

```shell
/usr/sbin
```
Содержит административные команды и демоны, которые не требуются для загрузки системы, но используются для её управления.
Примеры: sshd, useradd, cron, httpd


```shell
/etc (et cetera)
```
Содержит системные конфигурационные файлы и файлы настроек программ

```shell
/var (variable)
```
Содержит переменные данные, которые часто изменяются в процессе работы системы: логи, кэш, базы данных, почтовые очереди.
Поддиректории:
```shell
* /var/log/ — файлы журналов
* /var/cache/ — кэш приложений
* /var/lib/ — базы данных приложений
* /var/spool/ — очереди задач (печать, почта)
```

```shell
/tmp (temporary)
```
Содержит временные файлы, создаваемые программами и пользователями. Обычно очищается при перезагрузке системы.

```shell
/home
```
Содержит домашние каталоги обычных пользователей

```shell
/root
```
Домашний каталог суперпользователя root

```shell
/proc (process)
```
Виртуальная файловая система, которая предоставляет интерфейс к структурам данных ядра. Содержит информацию о процессах и параметрах системы в реальном времени
Особенности:
* Не занимает место на диске
* Файлы генерируются ядром на лету
* Содержит информацию о процессах (папки с PID) и параметрах ядра


```shell
/sys (system)
```
Виртуальная файловая система, которая экспортирует информацию об устройствах, драйверах и подсистемах ядра
Особенности:
* Позволяет не только читать, но и изменять некоторые параметры оборудования
* Появилась позже /proc для более структурированного представления информации
