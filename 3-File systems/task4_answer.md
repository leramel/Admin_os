# RAID-массивы
### 1. Что такое RAID и какие основные уровни RAID вы знаете?

RAID (Redundant Array of Independent Disks) — это технология виртуализации данных, которая объединяет несколько физических дисков в один логический элемент для повышения надёжности, производительности или того и другого.
Основные уровни:
* RAID 0 (Striping): Данные разбиваются на блоки и записываются параллельно на все диски.
  Плюсы: высокая скорость, 100% использование ёмкости. Минусы: нет отказоустойчивости (гибель одного диска - потеря всех данных).
* RAID 1 (Mirroring): Полное зеркалирование данных. Всё записывается одновременно на два диска.
  Плюсы: высокая надёжность. Минусы: полезная ёмкость равна ёмкости одного диска (50% потерь).
* RAID 5: Чередование с распределённой чётностью. Требуется минимум 3 диска. Выдерживает отказ одного диска.
* RAID 10: Комбинация RAID 1 и RAID 0 (зеркало из страйпов). Высокая скорость и надёжность, но дорого (нужно минимум 4 диска).

### 9. В чём практическая разница между RAID0 и RAID1?

* RAID 0 выбирают для скорости (например, для видеомонтажа или временных файлов), когда данные не критичны и есть резервная копия.
* RAID 1 выбирают для надёжности (например, для системного диска или важных баз данных), чтобы при выходе одного диска из строя система продолжила работать без потерь.

### 12. Какие файловые системы могут самостоятельно обеспечивать функции, похожие на RAID?
ZFS и Btrfs. Они имеют встроенные механизмы управления пулами дисков (vdev), зеркалирования и контроля чётности, что делает использование классического mdadm необязательным.

### 13. Можно ли создать RAID во время установки Linux?
Да. Большинство современных инсталляторов (включая ALT Linux) позволяют создать программный RAID на этапе разметки диска, до установки самой системы.
